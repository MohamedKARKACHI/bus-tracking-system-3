A comprehensive real-time bus tracking system with **ANPR** (Automatic Number Plate Recognition) capabilities.

## ✨ Features

- 🚌 **Real-time Bus Tracking** - Track buses on interactive maps with WebSocket updates
- 📸 **ANPR Integration** - AI-powered license plate recognition using YOLOv8
- 👤 **Multi-Portal System** - Admin, Driver, and Client portals
- 🎫 **Ticket Booking** - Online ticket reservation system
- 📍 **Route Management** - Dynamic route planning and optimization

## 🛠️ Tech Stack

| Component | Technology |
|-----------|------------|
| **Frontend** | Next.js 16, React 19, TypeScript, Tailwind CSS |
| **Backend** | Spring Boot 3, Java 21 |
| **AI/ML** | Python, YOLOv8, EasyOCR |
| **Database** | MySQL (MAMP) |
| **Real-time** | WebSocket, Socket.io |
| **Maps** | Mapbox GL |

## 🚀 Quick Start

```bash
# Start all services (Frontend, Backend, ANPR)
./start-all.sh
```
