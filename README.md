# Bus Tracking System 3

A comprehensive real-time bus tracking system with ANPR (Automatic Number Plate Recognition) capabilities.

## Features

- 🚌 **Real-time Bus Tracking** - Track buses on interactive maps
- 📸 **ANPR Integration** - Automatic license plate recognition using YOLOv8
- 👤 **Multi-Portal System** - Admin, Driver, and Client portals
- 🎫 **Ticket Booking** - Online ticket reservation system
- 📍 **Route Management** - Dynamic route planning and optimization

## Tech Stack

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **Backend**: Spring Boot, Java
- **AI/ML**: Python, YOLOv8, EasyOCR
- **Database**: PostgreSQL
- **Maps**: Mapbox GL

## Quick Start

```bash
# Start all services
./start-all.sh
```
